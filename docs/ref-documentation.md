# Documentation – Reference
- OpenAPI spec in `openapi.yaml`
- Validate with `swagger-cli validate openapi.yaml`
- Serve interactive docs via Redoc or Swagger UI on GitHub Pages
- Add version header `X-Version: vX.Y.Z`
- Keep `CHANGELOG.md` for breaking changes
- CI badge for docs build status
- Contribution: fork → edit → PR; run `markdownlint`
